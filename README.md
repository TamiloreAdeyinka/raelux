# Raeluxe Interiors Homepage

Standalone homepage implementation for Raeluxe Interiors (interior design, renovation &amp; fit-out, furnishing &amp; styling).

## Run Locally

```bash
npm run dev
```

The local server prints the URL, usually `http://localhost:5173`.

## Build

```bash
npm run build
```

The production output is written to `dist/`.

## Deploy On Vercel

Push this folder to GitHub, import it in Vercel, and keep the defaults from `vercel.json`:

- Build command: `npm run build`
- Output directory: `dist`

No runtime environment variables are required.
